# SMS Spam Detection with NLP

This project demonstrates SMS spam classification using classical NLP preprocessing and multiple vectorization approaches in a Jupyter notebook.

## What is included

- Text cleaning and preprocessing with NLTK
- Bag of Words model
- TF-IDF model
- Word2Vec from scratch
- Average Word2Vec sentence embeddings
- Spam classification using Multinomial Naive Bayes

## Files

- `Day 5- NLP Word2vec And AvgWord2vec.ipynb` - main notebook
- `SMSSpamCollection.txt` - SMS spam dataset


## Brief description

The notebook builds a spam detection pipeline for SMS messages. It preprocesses the text, transforms it into numerical features using Bag of Words, TF-IDF, and Word2Vec-based sentence vectors, and then trains a Naive Bayes classifier to separate spam from ham messages.
